SECTION 1 · What Is This Project?
PMDD stands for Pragmatic Meaning Drift Detector. It is a 5-agent AI application built on Antigravity IDE that analyses how language meaning shifts across a document or corpus — automatically, using proven academic linguistic theories.
Simple Analogy
A doctor does not just say 'you look sick.' They run blood tests, X-rays, and produce a report with evidence. PMDD does the same for language. Instead of saying 'the tone changed,' it runs 5 AI tests and reports exactly WHICH words shifted, WHERE, and WHY — citing the academic theory that explains it.
1.1  What PMDD Does
You upload a text file (political speech, academic paper, news archive, company reports). You type target keywords. PMDD's five agents work one by one to produce a full linguistic drift report with a Drift Score out of 100.

SECTION 2 · The Five Agents — Who Does What?
Each agent has ONE job. They run in sequence: 1 → 2 → 3 → 4 → 5. Agent 5 can also ask any earlier agent to re-run if quality is insufficient.
🔵
AGENT 01
Corpus Preprocessor
Reads your raw file, cleans it, and splits it into numbered segments (S001, S002…) that all other agents use.
INPUT: 
Raw uploaded file (.txt / .csv / .pdf / .json)
OUTPUT: 
Structured JSON: [{id, text, word_count, position, section}]
🟢
AGENT 02
Pragmatic Analyzer
Reads every segment and classifies what each sentence is DOING — asserting, commanding, promising, evaluating. Also detects politeness and Grice violations.
INPUT: 
Segments JSON from Agent 1
OUTPUT: 
Enriched JSON: speech_act, politeness_score, maxim_violations, implicature_type per segment
🟣
AGENT 03
Semantic & Register Detector
Tracks what your target keywords MEAN in each section. Detects if a word moves from one semantic field to another. Also classifies register: formal, informal, academic, colloquial.
INPUT: 
Segments + target keywords
OUTPUT: 
Semantic drift map per keyword + register classification per segment
🟡
AGENT 04
Corpus Statistician
Runs mathematics: word frequency, collocation, MI score, keyness, Type-Token Ratio. Proves the drift findings with numbers.
INPUT: 
Annotated segments
OUTPUT: 
Frequency tables, collocations, MI scores, TTR per section
🔴
AGENT 05
Orchestrator & Report Writer
Collects all four outputs, checks quality, calculates the Drift Score, and writes the full academic linguistic report. Can trigger re-analysis of any earlier agent.
INPUT: 
All outputs from Agents 1–4
OUTPUT: 
Full report (Markdown) + Evidence JSON + Dashboard Drift Score

STEP 2  ·  PROMPT FOR AGENT 2 — Pragmatic Analyzer
FILE TO SAVE: agents/agent2_pragmatic.py
PASTE THIS PROMPT INTO ANTIGRAVITY AI:
Write a Python file called agent2_pragmatic.py for a linguistics project.
This is Agent 2 (Pragmatic Analyzer) of a 5-agent PMDD system.
The system prompt below MUST be used exactly as written — it defines the linguistic
framework for the agent. Do not paraphrase or shorten it.
SYSTEM PROMPT FOR GPT-4o (embed this as a string variable called AGENT2_SYSTEM_PROMPT):
---
You are an expert computational linguist specialising in pragmatics.
Your task is to analyse a text segment using three precise linguistic frameworks.
FRAMEWORK 1 — SPEECH ACT THEORY (Searle 1969):
Classify the dominant speech act as exactly one of:
  - assertive: states a fact, belief, or description
  - directive: commands, requests, or instructs the listener
  - commissive: commits the speaker to a future action (promises, pledges)
  - expressive: expresses emotional or evaluative stance
  - declarative: changes reality by being spoken (official proclamations)
Also provide a Layer 4 sub-type — a specific function such as:
  evaluative_assertion, compliance_framing, indirect_directive,
  solidarity_appeal, threat_implication, hedge_assertion
FRAMEWORK 2 — GRICEAN MAXIMS (Grice 1975):
Identify any violations of the Cooperative Principle:
  - Quantity: too much or too little information given
  - Quality: unverifiable, vague, or potentially false claim
  - Relation: segment seems off-topic or irrelevant
  - Manner: unclear, ambiguous, or unnecessarily verbose
If no violation: return []
FRAMEWORK 3 — POLITENESS THEORY (Brown & Levinson 1987):
Score politeness on a scale of 1 to 5:
  1 = very face-threatening (aggressive, dismissive, authoritarian)
  2 = mildly face-threatening
  3 = neutral
  4 = polite (hedging, inclusive language)
  5 = highly polite (deferential, solidarity-building)
Return ONLY valid JSON with this exact structure — no other text:
{
  'speech_act': 'assertive',
  'speech_act_subtype': 'evaluative_assertion',
  'maxim_violations': ['Quality', 'Manner'],
  'implicature': 'conventional',
  'politeness_score': 2,
  'evidence': 'The exact quoted phrase that triggered this classification'
}
---
CODE REQUIREMENTS:
1. Import openai and json
2. Create a variable API_KEY = 'YOUR_OPENAI_API_KEY_HERE' at the top
3. Create a function analyze_segment(segment_text: str) -> dict that calls GPT-4o
   with temperature=0.1 and the system prompt above
4. Parse the JSON response — if parsing fails, return a default dict with
   speech_act='unknown' and empty fields
5. Create a main function run_agent2(segments: list) -> list that loops through
   all segments, calls analyze_segment() for each, and merges the result
   into each segment dict
6. Print progress: 'Agent 2: Analysing segment S001 of 150...' for each segment
7. Add a rate-limit safety: add time.sleep(0.5) between each API call
8. Return the enriched list of segment dicts
STEP 3  ·  PROMPT FOR AGENT 3 — Semantic & Register Detector
FILE TO SAVE: agents/agent3_semantic.py
PASTE THIS PROMPT INTO ANTIGRAVITY AI:
Write a Python file called agent3_semantic.py for a linguistics project.
This is Agent 3 (Semantic Field and Register Detector) of a 5-agent PMDD system.
SYSTEM PROMPT FOR GPT-4o (store as AGENT3_SYSTEM_PROMPT string):
---
You are an expert computational linguist specialising in semantic field theory
and register analysis.
TASK 1 — SEMANTIC FIELD ANALYSIS (Lyons 1977):
For each provided target keyword, analyse how it is used in the given corpus section.
Classify its semantic field as one of:
  social_identity | political_power | institutional_authority | conflict |
  solidarity | affect | economic | technological | environmental | cultural
Classify its Layer 4 semantic function as one of:
  boundary_exclusion | agency_assertion | compliance_framing |
  threat_implication | solidarity_marker | authority_claim |
  hedged_commitment | ideological_framing | mobilisation_appeal
Identify the DRIFT TYPE compared to earlier sections:
  field_transfer   — the word has moved to a completely different semantic field
  strengthening    — the word has gained stronger/more intense meaning
  weakening        — the word has lost intensity or been euphemised
  narrowing        — the word now applies to a smaller set of referents
  broadening       — the word now applies to a wider set of referents
  no_drift         — meaning is stable
Classify PROSODY (the emotional charge the word attracts):
  positive | negative | neutral | mixed
List the 5 most common words appearing near this keyword in the section.
Write a CONNOTATION NOTE: a minimum 40-word academic explanation of what this
keyword is ideologically doing in this section of the text.
TASK 2 — REGISTER ANALYSIS (Halliday 1978):
For the entire section text, classify the register as:
  formal | semi-formal | informal | technical | colloquial | academic | political
Note any REGISTER BORROWING — where formal vocabulary appears in informal context
or vice versa.
Return ONLY valid JSON — no other text:
{
  'keyword_analyses': [
    {
      'keyword': 'democracy',
      'section': 'Section_1',
      'semantic_field': 'political_power',
      'semantic_subtype': 'agency_assertion',
      'drift_type': 'field_transfer',
      'prosody': 'positive',
      'top_collocates': ['freedom', 'values', 'protect', 'our', 'restore'],
      'connotation_note': '40+ word explanation here'
    }
  ],
  'register': 'political',
  'register_borrowing': 'Academic term sovereignty used in populist informal context'
}
---
CODE REQUIREMENTS:
1. Import openai, json, collections
2. Variable API_KEY = 'YOUR_OPENAI_API_KEY_HERE'
3. Function run_agent3(segments: list, keywords: list, section_labels: list) -> dict
4. Group segments by section label
5. For each section, build a combined text from all segment texts in that section
6. Call GPT-4o with the system prompt above, passing: the section text + keywords list
7. Collect all keyword analyses into a drift map: {keyword: [list of section analyses]}
8. Return the full structured dict
9. Print progress per section
STEP 4  ·  PROMPT FOR AGENT 4 — Corpus Statistician
FILE TO SAVE: agents/agent4_statistics.py
PASTE THIS PROMPT INTO ANTIGRAVITY AI:
Write a Python file called agent4_statistics.py for a linguistics project.
This is Agent 4 (Corpus Statistician) of a 5-agent PMDD system.
This agent uses pure Python mathematics — it does NOT call the GPT-4o API.
REQUIRED FUNCTIONS:
1. compute_frequency(segments: list) -> dict
   - Use collections.Counter to count word frequencies in each corpus section
   - Return top 20 content words per section (exclude stopwords from NLTK)
   - Format: {'Section_1': [('democracy', 45), ('people', 38), ...], 'Section_2': [...]}
2. compute_ttr(segments: list) -> dict
   - Type-Token Ratio = unique_words / total_words for each section
   - Higher TTR = more diverse vocabulary
   - Return: {'Section_1': 0.72, 'Section_2': 0.61}
3. compute_collocations(segments: list, keywords: list, window: int = 5) -> dict
   - For each keyword, find all words appearing within a 5-word window
   - Count how often each collocate appears
   - Return top 10 collocates per keyword per section
   - Format: {'democracy': {'Section_1': [('freedom', 12), ...], 'Section_2': [...]}}
4. compute_mi_score(word1_freq, word2_freq, bigram_freq, total_words) -> float
   - Mutual Information: log2((bigram_freq * total_words) / (word1_freq * word2_freq))
   - Returns a float: MI > 3.0 indicates significant collocation
5. compute_keyness(section_a_words: list, section_b_words: list) -> list
   - Find words that are statistically more frequent in section_a vs section_b
   - Use simple log-likelihood ratio
   - Return top 15 keywords with scores
   - Format: [{'word': 'security', 'keyness_score': 34.2, 'section': 'Section_2'}]
6. run_agent4(segments: list, keywords: list) -> dict
   - Calls all functions above
   - Returns combined dict with keys: frequencies, ttr, collocations, keyness
   - Print progress messages for each computation step
Use only: collections, math, nltk, re, pandas — NO openai library in this file.
Download NLTK stopwords with: nltk.download('stopwords') at the top.

SECTION 7 · Common Errors and How to Fix Them
Error
Fix
ModuleNotFoundError: spacy
Run: pip install spacy  then  python -m spacy download en_core_web_sm
AuthenticationError: Invalid API key
Double-check your API key — copy it fresh from platform.openai.com
RateLimitError from OpenAI
Increase the time.sleep() value in agent2 from 0.5 to 1.5 seconds
JSONDecodeError when parsing response
Use the safe_json_parse() helper from helpers.py — it catches bad JSON
FileNotFoundError for corpus
Make sure your file is uploaded and the path is correct
Gradio port already in use
Change demo.launch() to demo.launch(server_port=7861)
Agent 5 reports quality check failed
Reduce your corpus to a simpler .txt file first for testing
ImportError for agents module
Make sure agents/__init__.py file exists (can be empty)
