What is PMDD? — Plain English Explanation           PMDD stands for Pragmatic Meaning Drift Detector.           Imagine you are reading a long document — a government report, a politician's speeches over years, a company's annual reports, or a news archive. On the surface the words look similar throughout. But something feels different between the beginning and the end. The tone has changed. The language feels harder, or softer, or more aggressive, or more bureaucratic.           PMDD is a tool that detects exactly that — it finds when and how the meaning of language shifts across a document or collection of documents, and explains WHY it shifted, using proven academic theories.           Think of it like this:           A doctor does not just say 'you look sick.' They run specific tests — blood pressure, cholesterol, X-ray — and produce a detailed report with evidence. PMDD does the same for language. It does not just say 'the tone changed.' It runs five specialised tests using five AI agents and produces a deep report with evidence: which words, in which section, triggered the shift, and what linguistic theory explains it. Understanding the Results — Each Agent Card            Agent 1 · Corpus Preprocessor           Shows: Total sections · Total segments · Total tokens · Total types · TTR           A segment is typically 1–3 sentences grouped together. Each gets a unique ID (S001, S002…) that all other agents use for evidence citations. You do not need to do anything with Agent 1's output — it is the foundation all other agents build on.            Agent 2 · Pragmatic Analyzer           Shows a live table of segments with their Speech Act classification. For each segment:          Layer 3 — the speech act type (assertive / directive / commissive / expressive / declarative)          Layer 4 — the specific function (e.g. evaluative_assertion, indirect_directive, compliance_framing)          Politeness score — 1 (very aggressive) to 5 (very polite)          Evidence — the quoted text from your document that triggered the classification          Grice violations — if any cooperative maxim was broken in that segment           If your document has more than 100 segments, Agent 2 takes an evenly-spaced sample of 100 representative segments (shown in an amber badge). Agent 3 · Semantic &amp; Register Detector           Shows two panels for each keyword:           Semantic Field Analysis per Keyword (accordion per keyword):          Section — which section of the document          Semantic L3 — the field the keyword belongs to (social_identity / political_power / institutional_authority / conflict / solidarity / affect)          Semantic L4 — the specific function within that field (e.g. boundary_exclusion, agency_assertion, compliance_framing)          Drift Type — how the meaning has shifted (field_transfer / strengthening / weakening / narrowing / broadening)          Prosody — the emotional charge the keyword attracts (positive / negative / neutral / mixed) — colour coded          Top Collocates — the 5 most common words appearing near the keyword in that section          Connotation Note — a 40+ word explanation of what the keyword is ideologically doing in that section          Evidence text — quoted from your document           Register Analysis — Field · Tenor · Mode (table, one row per section):          Field L3/L4 — what domain the text belongs to (academic / journalistic / political / informal)          Tenor L3/L4 — the power relationship (institutional_formal / interpersonal_informal / adversarial)          Mode L3/L4 — how the language is structured (written_formal / written_informal)            Agent 4 · Corpus Statistician           Shows per-keyword statistical panels (one accordion per keyword):          Frequency Trajectory — how often the keyword appears in each section (raw count + per-1000-words + bar chart)          Collocates with MI Score — which words appear near the keyword and how strongly (MI &gt; 3.0 = strong association)          Keyness (LL Test) — is the keyword statistically unusual in any section? The 12 Linguistic Theories Behind the System           Every classification, score, and finding in PMDD is grounded in one of the 12 peer-reviewed academic theories below. The theories are displayed on the app page and as coloured badges on each agent card.            Agent 2 — Pragmatic Analysis (4 Theories)         Theory 1 &amp; 2: Speech Act Theory                            Field                 Details                Authors              John Searle (1969) · J.L. Austin (1962)                Publications              Speech Acts, Cambridge University Press · How to Do Things with Words, Oxford University Press                Plain English              Every sentence is not just information — it is an action. Saying 'I promise' performs a promise. Saying 'You must comply' performs a command. Searle classified all speech actions into five types.                Role in PMDD              Agent 2 classifies every segment's speech act at four levels. If a document shifts from Assertives (neutral claims) to Directives (commands) or Commissives (threats/promises) — that is pragmatic drift.                                 Speech Act                 Plain Meaning                 Example                Assertive              Speaker claims something is true              The data shows a clear pattern.                Directive              Speaker tries to make someone do something              You must comply immediately.                Commissive              Speaker commits to a future action              We will take all necessary measures.                Expressive              Speaker expresses emotion or evaluation              This is deeply concerning.                Declarative              Speaker changes reality by speaking              The committee hereby declares…             Theory 3: Gricean Maxims (Cooperative Principle)                            Field                 Details                Author              H.P. Grice (1975)                Publication              Logic and Conversation, in Cole &amp; Morgan (Eds.), Syntax and Semantics                Plain English              When people communicate cooperatively, they follow four unwritten rules. When a speaker deliberately breaks a rule, they create hidden meaning (implicature).                Role in PMDD              Agent 2 detects which maxim is violated in each segment. A text full of Quantity violations (over-qualification) is very different from one with Quality violations (unverified claims).                                 Maxim                 Rule                 Violation Means                Quantity              Say enough but not too much              Over-hedging every claim, or leaving out key facts                Quality              Say only what you believe              Unverified claims: 'Some say…', 'It is alleged…'                Relation              Stay on topic              Abrupt subject changes with no logical connection                Manner              Be clear and orderly              Ambiguous pronouns, circular or verbose sentences             Theory 4: Politeness Theory                            Field                 Details                Authors              Penelope Brown &amp; Stephen Levinson (1987)                Publication              Politeness: Some Universals in Language Usage, Cambridge University Press                Plain English              Every person has a 'face' — a public self-image. Language either supports that face or attacks it. When face management changes across a text (from solidarity to aggression), that reveals changing power dynamics.                Role in PMDD              Agent 2 assigns a politeness score (1–5) and classifies the face management strategy per segment. Shift from Positive Face strategies to Face-Threatening Acts = escalation in communicative aggression.                Agent 3 — Semantic &amp; Register Analysis (4 Theories)         Theory 5: Lexical Semantics                            Field                 Details                Author              Geoffrey Leech (1974)                Publication              Semantics, Penguin                Plain English              Words do not have fixed meanings — they have a range of meanings depending on context and surrounding words. Meaning has multiple layers: conceptual (dictionary), connotative (cultural), and affective (emotional charge).                Role in PMDD              Agent 3 classifies each keyword into a semantic field with a 4-layer tag. If a keyword shifts semantic field across sections, its meaning has drifted. This is the core of the semantic drift score.                                 Semantic Field                 Plain Meaning                 Example Keywords                social_identity              Group membership, in-group vs out-group              community, people, citizens, nation                political_power              Governance, authority, political agency              government, state, mandate, enforce                institutional_authority              Formal rules, bureaucracy, compliance              policy, regulation, board, committee                conflict              Tension, opposition, confrontation              against, threat, attack, condemn                solidarity              Mutual support, unity, cooperation              together, shared, united, support                affect              Emotional states, evaluative stances              hope, fear, proud, concern, urgent             Theory 6: Register Theory (Systemic Functional Linguistics)                            Field                 Details                Author              M.A.K. Halliday (1978)                Publication              Language as Social Semiotic, Edward Arnold                Plain English              Language style (register) is determined by three factors: the Field (what topic), the Tenor (who is speaking to whom and their power relationship), and the Mode (spoken vs written, formal vs informal).                Role in PMDD              Agent 3 produces three separate register tags per section — Field, Tenor, and Mode. Shifts in Tenor (e.g. from interpersonal-informal to institutional-formal) show that the social relationship constructed by the text has changed.                                 Dimension                 What It Measures                 Example Shift                Field              The subject matter domain              Academic → Political                Tenor              Power and relationship between writer/reader              Informal solidarity → Formal authority                Mode              How formal and structured the language is              Conversational → Nominal/bureaucratic             Theory 7: Corpus Lexical Semantics                            Field                 Details                Author              Michael Stubbs (2001)                Publication              Words and Phrases: Corpus Studies of Lexical Semantics, Blackwell                Plain English              A word's real meaning is best revealed not by its dictionary definition but by the company it keeps — the words that regularly appear near it. 'Asylum' collocating with 'refugee, protection' means something very different to 'asylum' with 'burden, flood, crisis'.                Role in PMDD              Guides how Agent 3 and Agent 4 interpret collocate evidence. The collocates found around each keyword in each section are the primary evidence for semantic field classification and the 'collocates_found' list in each keyword panel.             Theory 8: Discourse Analysis                            Field                 Details                Author              James Paul Gee (2014)                Publication              An Introduction to Discourse Analysis, Routledge                Plain English              Discourse analysis asks not just what language means but what it does in the world — how it constructs identities, power relationships, and social realities. The same event described in two discourses produces two completely different social realities.                Role in PMDD              Informs how Agent 3 writes connotation notes (the 40+ word ideological analysis per keyword) and how Agent 5 synthesises the overall drift narrative into a socially grounded academic report.                Agent 4 — Corpus Statistics (4 Theories)         Theory 9: Corpus Linguistics                            Field                 Details                Author              John Sinclair (1991)                Publication              Corpus, Concordance, Collocation, Oxford University Press                Plain English              Sinclair established that meaning is built not by individual words but by extended lexical units — words plus their typical collocates. He introduced the ±5-word window as the standard for collocation analysis and showed that language is primarily idiomatic (fixed patterns dominate).                Role in PMDD              The ±5-word collocation window Agent 4 uses for all MI calculations. Also the basis for n-gram (bigram/trigram) analysis and the 'Sinclair (1991) — ±5 window' badge on the Agent 4 collocates table.             Theory 10: Corpus Linguistics Methodology                            Field                 Details                Authors              Tony McEnery &amp; Andrew Wilson (2001)                Publication              Corpus Linguistics, Edinburgh University Press                Plain English              McEnery &amp; Wilson formalised how to design and statistically analyse a corpus. Their methodology defines how normalisation works and how to compare sub-corpora — in PMDD, each section of the document is treated as a sub-corpus.                Role in PMDD              The normalised frequency calculations (per 1000 words), section-by-section comparison design, and threshold definitions for 'significant' vs 'stable' frequency changes all follow McEnery &amp; Wilson's standards. Shown in the frequency trajectory table.             Theory 11: Log-Likelihood Keyness                            Field                 Details                Author              Ted Dunning (1993)                Publication              Accurate Methods for the Statistics of Surprise and Coincidence, Computational Linguistics                Plain English              The Log-Likelihood test answers: 'Is this word appearing unusually often in this section — more than chance would predict?' Unlike simple frequency counts, LL gives a statistical confidence level (like p&lt;0.01 in science experiments).                Role in PMDD              Agent 4 runs a LL keyness test on every keyword comparing each section to the rest of the corpus. Shown as KEY p&lt;.01 / KEY p&lt;.05 / not key badges in the keyword panels.                                 LL Score                 Confidence Level                 Meaning in Your Analysis                &gt; 6.63              p &lt; 0.01 (99%)              Word is statistically KEY — very strong evidence of drift in this section                3.84 – 6.63              p &lt; 0.05 (95%)              Borderline key — possible shift, treat with moderate confidence                &lt; 3.84              Not significant              No statistical evidence of shift in this section             Theory 12: Mutual Information                            Field                 Details                Authors              Kenneth Church &amp; Patrick Hanks (1990)                Publication              Word Association Norms, Mutual Information and Lexicography, Computational Linguistics                Plain English              MI measures how strongly two words are attracted to each other. If 'nuclear' and 'family' appear together far more than chance predicts, their MI is high — they form a genuine meaning unit. Low MI means co-occurrence is accidental.                Role in PMDD              Agent 4 calculates MI scores for each keyword's top collocates. High MI collocates reveal the keyword's semantic core in that section. If high-MI collocates change between sections, the keyword's meaning has shifted. Agent 2 is the longest — it analyses up to 100 representative segments in batches of 10, making approximately 10 AI calls. Agent 5 report generation can take up to 60 seconds.          What file formats are supported?      PDF, plain text (.txt), CSV (.csv), and JSON (.json). For PDF, the tool extracts the raw text — scanned or image-only PDFs will not work.          Do I need an account or API key?      No. The OpenAI key is built into the server. You just use the web interface at https://pmddproject-black.vercel.app          What if one agent fails?      Each agent runs independently. If one agent fails, its card shows an error message. The other agents can still complete. You can re-run just that agent using the feedback re-run button.          Can I analyse any language?      The framework is designed for English. Other languages may produce partial results as the theoretical markers (e.g. Gricean violation markers, politeness strategies) are defined for English linguistic patterns.          What is a 'segment'?      A segment is typically one to three sentences grouped together by Agent 1. Each segment gets a unique ID (S001, S002…) that all subsequent agents reference for evidence tracking.          Why does Agent 2 only analyse 100 segments?      Speed. A 200-page document may have over 1,000 segments. Analysing all per-segment would take over an hour. Agent 2 takes an evenly-spaced representative sample of 100 — preserving the full distribution while keeping analysis under 2 minutes. A badge on the card tells you if sampling was applied.          Why is Agent 3 showing a scheme error in validation?      This is a cosmetic metadata issue — Agent 3 has two layer1 values (lexical_semantics and register) so its tagging scheme uses 'layer1_semantic' and 'layer1_register' instead of a single 'layer1' key. The validator expects a single 'layer1'. This does NOT affect the analysis quality — 0 tag errors means all the actual linguistic analysis is valid.          How does the feedback improve future runs?      When you submit a rating of 1 or 2 stars with a comment, your comment is stored in the agent's episodic memory. On the next run, the comment is injected into the agent's system prompt as an 'active improvement' — the agent is told specifically what you wanted done differently.       ────────────────────────────────────────────────────────────────────────────────              PMDD v2.1  ·  May 2026  ·  https://pmddproject-black.vercel.app   Five-agent AI pipeline  ·  GPT-4o  ·  12 peer-reviewed linguistic theories
